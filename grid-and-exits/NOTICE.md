# Notice

The grid and exit rules this skill describes (triple barrier: stop-loss, take-profit, time limit and trailing stop;
grid levels with a take-profit per level) follow Hummingbot's `strategy_v2` executors
(https://github.com/hummingbot/hummingbot, `hummingbot/strategy_v2/executors/`), which are licensed under the Apache
License, Version 2.0 (https://www.apache.org/licenses/LICENSE-2.0). Orbie ported the rules to its own code; this skill
describes them in its own words.
